# script_theatre — remise en forme

Photos de pages imprimées (théâtre, roman…) → document Word mis en forme selon un profil. L'outil intègre aussi, chaque semaine, les annotations manuscrites des répétitions, en suivi des modifications Word, au nom de chaque personne.

- **Application web** : la page `index.html`, publiée avec GitHub Pages. Elle fonctionne sur téléphone, sans installation ; chacun saisit sa propre clé d'API Anthropic.
- **Ligne de commande** : `python -m remise_en_forme …`

Mode d'emploi complet : [LISEZMOI.md](LISEZMOI.md).
